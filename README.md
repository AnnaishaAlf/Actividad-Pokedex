# Creación de Cuenta en Vercel para el Despliegue de la Aplicación PokeDex

Este documento describe el proceso paso a paso que seguí para crear una cuenta en **Vercel** y prepararme para desplegar la aplicación **PokeDex**.

Registro en Vercel

1. Ingresé al sitio oficial de Vercel: [https://vercel.com](https://vercel.com)
2. Hice clic en el botón **"Sign Up"** (Registrarse).
3. Seleccioné la opción **"Continuar con GitHub"**.
4. Autoricé a Vercel para que accediera a mi cuenta de GitHub, permitiendo ver y gestionar mis repositorios.
5. Elegí el plan gratuito (Free).
6. Entre a mi cuenta
